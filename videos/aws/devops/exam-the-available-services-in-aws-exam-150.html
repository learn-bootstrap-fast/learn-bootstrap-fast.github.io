The correct answer is buildspec.yml. This file, written in YAML format, is required by AWS CodeBuild to define the set of phases and commands the service should execute as part of the build process. The buildspec.yml file can either be placed at the root of your source code repository or explicitly defined in your CodeBuild project settings.

appspec.yml and appspec.json pertain to AWS CodeDeploy, not CodeBuild. These files define how deployments should be carried out, not how code should be built. Choosing either would not work for a CodeBuild configuration.

buildspec.xml is not a valid file type for CodeBuild—the service expects build commands in the YAML-formatted buildspec.yml file.

Tips and Insights: Always use YAML formatting and ensure that the filename is exactly buildspec.yml. This guarantees compatibility and helps CodeBuild automatically pick up the file and execute the commands you define within it.

Key takeaway: For CodeBuild builds, always use a buildspec.yml file to provide your build instructions.
