Leverage nested stacks by breaking functionality into individual templates, then linking them using CloudFormation. is the best approach. This method promotes modularity and maintainability by dividing resources based on their functionality (such as networking, databases, compute, etc.), making each template easier to manage, update, and reuse. Nested stacks enable you to compose complex infrastructure by referencing smaller, purpose-driven templates, which improves agility and streamlines environment management. You can maintain version control for each template individually and rapidly deploy changes to specific stack components without having to redeploy entire application stacks, reducing operational costs and risk.

Integrate CloudFormation custom resources so that dependencies across stacks are managed outside native stack support. is not ideal in this scenario since custom resources should only be used for actions that are not natively supported in CloudFormation, and dependency management is better handled using built-in features like nested stacks or stack outputs.

Large monolithic templates can quickly become difficult to manage, hard to troubleshoot, and slow to update, which reduces agility and makes reuse or cost optimization difficult.
