AWS CloudWatch is the correct choice because it provides detailed monitoring, logging, and alarm capabilities to track application and infrastructure health in real time. In Blue-Green deployments, CloudWatch can be used to set up health checks, alarms, and automated actions based on metrics, ensuring the new environment is performing correctly before any switch-over.

AWS CodePipeline helps automate the software release process but does not itself monitor application health. AWS CloudTrail focuses on logging and tracking API activity across your AWS environment, not health checks. AWS CodeCommit is a source control service and is unrelated to health monitoring.

  • Tip: For automated and operational visibility during deployments, always leverage CloudWatch for comprehensive monitoring and alerting.
  • Trick: Keep in mind that CloudWatch integrates with ELB and Auto Scaling for automatic response to unhealthy instances.
