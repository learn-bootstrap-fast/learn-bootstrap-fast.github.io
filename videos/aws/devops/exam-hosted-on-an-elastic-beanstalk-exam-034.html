The best strategy for achieving the fastest update of your Elastic Beanstalk environment is the Deploy all updates simultaneously across all instances method (also dubbed 'All at once'). This option replaces the application version on every environment instance immediately, resulting in the quickest possible deployment.

The other options do not match your speed requirement for the following reasons:

Deploy the update to instances in set groups one after the other (rolling batches) and Deploy changes to multiple instances at a time using batches before proceeding to the next group (both referring to rolling and rolling with batch deployments) carry out updates in groups, which is safer for high-availability but significantly slows down the deployment as not all instances are updated at once.

Use a strategy that requires replacement of every instance during deployment (immutable) ensures that the deployment is performed without modifying existing servers, by provisioning new instances and switching traffic only after successful deployment, but this is slower and involves additional instance launches.

Tip: While Deploy all updates simultaneously across all instances is the fastest deployment approach, it comes with brief downtime, as all instances are taken out of service simultaneously during the update process. Use this method only when minimal downtime is acceptable or in non-production environments.
