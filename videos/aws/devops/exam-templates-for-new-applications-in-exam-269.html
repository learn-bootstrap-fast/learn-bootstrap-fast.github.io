The correct choices are:
The Amazon SQS queue ARN. and An Amazon SNS topic ARN.

When you use the AWS::CloudFormation::CustomResource resource, the ServiceToken property tells CloudFormation where to send the custom resource requests (Create/Update/Delete events). Valid values include the ARN of an SNS topic or SQS queue. CloudFormation publishes a message to the endpoint you specify in ServiceToken, which can trigger actions via various means, such as Lambda or custom listeners.

Why other options are incorrect:
An ARN for a CloudWatch Event rule. – CloudWatch Event rules do not natively process CloudFormation custom resource invocations. CloudFormation can only send notifications to supported endpoints.
A Lambda function ARN. – Although you often use Lambda with custom resources, Lambda function ARNs are supported with the newer AWS::CloudFormation::Resource type, but not directly with AWS::CloudFormation::CustomResource, which requires an SNS topic or SQS queue ARN.
The name of an AWS Step Function state machine. – Step Function names or ARNs are not supported endpoints for ServiceToken. They cannot receive direct notifications from CloudFormation custom resources.

Tips: Remember that while Lambda custom resources are preferred for newer templates (using AWS::CloudFormation::Resource), legacy custom resources require SNS or SQS endpoints.
