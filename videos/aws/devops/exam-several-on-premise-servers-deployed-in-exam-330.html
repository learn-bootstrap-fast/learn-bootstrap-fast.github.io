An Ubuntu 16.04 Linux instance operating inside Oracle VirtualBox is NOT a suitable scenario for using AWS Server Migration Service (SMS). This is because AWS SMS currently supports migrations only from VMware vSphere environments and Microsoft Hyper-V/SCVMM platforms. It does not support virtual machines running in Oracle VirtualBox.

The other choices are all scenarios where SMS can be leveraged:

  • A Java workload running on a virtual machine managed by vSphere Enterprise – SMS fully supports VMware vSphere environments, allowing migration of VMs regardless of the guest OS or application stack.
  • A Windows Server 2012 environment operating in a Microsoft Hyper-V instance – Hyper-V is a supported hypervisor for AWS SMS, so you can migrate Windows VMs running on Hyper-V.
  • A virtual machine being managed by Microsoft System Center Virtual Machine Manager – SCVMM works alongside Hyper-V and is supported by AWS SMS, so migrations from SCVMM-managed environments are possible.

Tip: When planning migrations using AWS SMS, review the list of compatible virtualization platforms (vSphere, Hyper-V, SCVMM). Other hypervisors like VirtualBox or unsupported environments require different migration approaches, such as manual image creation or using AWS Application Migration Service (MGN) instead.

Summary: AWS SMS is unsuitable for VirtualBox-based VMs. You will need an alternative tool to move Linux servers from Oracle VirtualBox to AWS.
