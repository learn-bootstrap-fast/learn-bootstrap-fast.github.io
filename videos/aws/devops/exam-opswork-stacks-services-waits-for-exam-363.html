The other options are incorrect for the following reasons:

  • 20 minutes: This wait time is much longer than necessary; OpsWorks is designed to detect failures more quickly to facilitate prompt recovery actions.
  • 60 minutes: This is far too long and would delay remediation or recovery processes if a server is truly unresponsive.
