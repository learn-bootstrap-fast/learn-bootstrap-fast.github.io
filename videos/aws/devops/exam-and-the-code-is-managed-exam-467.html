This ensures developers retain full access to feature branches, but cannot push or merge directly to master, while the senior developer's permissions can be managed separately.

Option D misuses resource policies; branch specificity is not supported with Resource elements set to '*', and IAM policies are more appropriate for user/group controls at this granularity.
