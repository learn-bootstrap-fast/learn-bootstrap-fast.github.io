Amazon EC2 Systems Manager is the correct answer because it offers capabilities to automatically collect detailed software inventory from your EC2 instances and also simplifies operating system patching. It has 'Inventory' and 'Patch Manager' features designed exactly for these tasks.

Here's why the other options are not correct:

  • AWS CodeDeploy is primarily used for automating code deployments to EC2, Lambda, or on-premises instances, not for inventory gathering or patch management.
  • EC2 AMIs are machine images that store the configuration of an EC2 instance, but they do not provide ongoing inventory collection or patch functionality by themselves.
  • AWS Code Pipeline is an orchestration tool for continuous integration and delivery pipelines; it does not manage EC2 inventory or patch compliance.

Tip: When asked about automating operational tasks such as inventories and patches on EC2, think of Systems Manager. It is a versatile service for automating and managing EC2 instances at scale.
