The correct answer is Windows Server Core 2019. AWS CodeBuild does support several popular Linux distributions such as Ubuntu 18.04, Amazon Linux 2, and Red Hat Enterprise Linux Operating System. These operating systems are commonly used in build environments provided by AWS and are maintained with up-to-date runtime support for a variety of programming languages and tools.

However, Windows Server Core 2019 is not supported as a base build environment in CodeBuild. CodeBuild supports building on Windows, but only with the full Windows Server 2019 image, not the stripped-down Server Core variant. The Core edition is a minimal install that omits many of the Windows features used during builds, and thus it is not available in the standard build image selection. Attempting to select or provision this base image will result in an unsupported platform error.

  • Amazon Linux 2: Fully supported and in fact recommended for most build jobs targeting Linux platforms.
  • Ubuntu 18.04: Supported as a managed image by CodeBuild, suitable for a range of open-source tooling and applications.
  • Red Hat Enterprise Linux Operating System: CodeBuild provides images for RHEL workloads as well, supporting enterprises with RHEL needs.

Tip: When selecting images for CodeBuild, review the official AWS CodeBuild documentation for the latest supported platforms. Not all Windows or Linux variants are available; stick to standard, well-supported distributions for maximum compatibility and support.
