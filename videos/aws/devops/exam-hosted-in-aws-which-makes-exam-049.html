The correct choice is AWS CloudTrail. AWS CloudTrail records API calls made to AWS services, including DynamoDB, and captures details such as the caller's identity, the time of the call, the parameters, and most importantly for this question, the source IP address. With this data, you can satisfy IT security requirements for auditing access and tracking down where requests are coming from.

The other options are not suitable for this purpose: AWS CodeCommit is a fully managed source control service, unrelated to DynamoDB interaction logging. AWS CloudWatch offers monitoring and operational data collection (like logging performance metrics or alarms), but it does not directly capture the source IP of requests to DynamoDB. AWS CodePipeline is a CI/CD service used for automating code builds, tests, and deployments, and does not log API requests or their IP addresses to DynamoDB.

Tip: When auditing access or tracking actions in AWS, CloudTrail is the go-to service for capturing API usage logs and analyzing individual request details, including IP addresses. Always ensure the required service is enabled in your target region and that logging for DynamoDB is configured correctly.
