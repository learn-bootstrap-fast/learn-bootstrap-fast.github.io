For applications deployed with AWS CodeDeploy to EC2 or On-Premises platforms, you are required to include the appspec.yml file in the root of your source code bundle. This file describes exactly how CodeDeploy should deploy and manage your code, specifying the location of files, permissions, and lifecycle events.

Why are the other options incorrect?

  • appconfig.yml: This is not a recognized file by AWS CodeDeploy; it will be ignored if present and won't provide deployment instructions.
  • appspec.config: This is not a valid filename for CodeDeploy; the tool expects appspec.yml (YAML format) or appspec.json for some other environments.
  • appconfig.json: This is also incorrect as AWS CodeDeploy looks specifically for appspec.yml for EC2/On-Premises deployments, not configuration files named appconfig.json.

Tip: Always double check the file name and format required by deployment services—CodeDeploy's appspec.yml must be in YAML or JSON format, and the file name must be precise for deployments to succeed.
