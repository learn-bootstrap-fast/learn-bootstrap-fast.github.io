The correct method is to use the Amazon RDS Console to add Aurora Replicas to your existing Aurora DB cluster by choosing Actions → Add Reader. Adding Aurora Replicas increases the cluster's availability by distributing reads and providing automatic failover if the primary instance becomes unavailable. You do not need to delete or recreate the cluster, nor do you need to change its template for high availability—Aurora allows you to scale out by simply adding replicas.

In the Amazon RDS Console, select your Aurora DB cluster and add Aurora Replicas by using Actions → Add Reader. is correct because Aurora supports adding one or more replicas to an existing cluster at any time.
