The proper section to modify is the Outputs section. The Outputs section in a CloudFormation template is designed to return data, such as resource attributes, to you after stack creation. By specifying the DNS name of the load balancer in this section, you make it accessible for reference, automation, and user information purposes post-deployment.

The other choices are incorrect for the following reasons:

  • Parameters are used to input custom values when launching or updating a stack, but cannot return values after completion.
  • Mappings are static variables used for conditional settings during stack deployment (like region to AMI mapping), not for returning runtime values.
  • Resources define and configure AWS resources but do not present their attributes or return values for consumption after deployment.

Tip: Always use the Outputs section when you need to export key information, such as ARNs, IDs, or DNS names, from a stack. This practice is crucial when connecting resources across stacks or for troubleshooting post-deployment.
