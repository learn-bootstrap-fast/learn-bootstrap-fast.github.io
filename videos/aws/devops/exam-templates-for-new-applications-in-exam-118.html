The ServiceToken property for AWS::CloudFormation::CustomResource must direct requests to an endpoint that can handle those requests and respond in accordance with CloudFormation expectations. The The ARN of an Amazon SNS topic. and A Lambda function's ARN. are both valid endpoints. With SNS, you can have subscribers (such as Lambda functions) process the request, while a Lambda function can process and respond directly.

The options A Step Function state machine name. and The ARN for a CloudWatch Event rule. are incorrect because CloudFormation custom resources do not support sending requests to these targets; they do not provide the necessary request/response model for CloudFormation.

Similarly, An SQS queue's ARN. is also invalid, as CloudFormation does not integrate with SQS for custom resource communication.

Tip: AWS CloudFormation custom resources require direct interaction with resources that can process and respond to the specific signaling contracts of CloudFormation, which is why SNS topics or Lambda functions are the main supported types.
