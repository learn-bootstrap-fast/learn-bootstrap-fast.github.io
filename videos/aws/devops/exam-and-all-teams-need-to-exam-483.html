The correct answer is AWS Config.

AWS Config is primarily a configuration auditing and compliance monitoring service. While it provides detailed visibility into resource configurations and changes over time, it does not directly provide recommendations or reporting for cost optimization. Its main functions involve tracking changes, compliance auditing, and troubleshooting operational issues, rather than identifying or suggesting opportunities to reduce AWS spending.

The other tools listed are all valuable in cost-optimization initiatives for the following reasons:

  • AWS Trusted Advisor offers built-in recommendations on cost optimization, security, fault tolerance, and resource utilization, helping teams find ways to reduce costs and improve efficiency.
  • AWS Cost and Usage Reports deliver highly detailed cost and usage data, allowing teams to analyze expenses and discover actionable insights for savings.
  • Amazon S3 Analytics provides analytics on storage access patterns, helping identify opportunities to transition objects to lower-cost storage classes.

Tip: Cost optimization tools typically provide suggestions, reports, or analytics directly aimed at reducing expenditures. Compliance and configuration tracking tools, like AWS Config, are less likely to contribute directly to cost reduction.
