The correct option is Cloud Spanner.

This service is a fully managed relational database that provides true distributed transactions with strong consistency, so it satisfies the full ACID requirement. It offers automated backups and point in time recovery which makes restores straightforward. It can scale horizontally by adding compute capacity and splits data automatically while keeping availability high and maintenance operations online, which minimizes downtime as traffic grows.

AlloyDB for PostgreSQL is optimized for high performance and compatibility with PostgreSQL and it supports ACID, yet it does not provide transparent horizontal write scaling. It can scale reads with read pools but writes are bound to a primary, so it does not meet the need for horizontal scaling with minimal downtime as demand increases.

Cloud SQL is a managed relational service with automated backups and ACID support, but it primarily scales vertically and offers read replicas only for read scaling. Write scaling is limited and failover or maintenance can introduce more downtime compared to a distributed database, so it does not fit the horizontal scaling requirement.

Cloud Bigtable scales massively and offers low latency, but it is a NoSQL wide column store without full multi row ACID transactions. It does not meet the transactional consistency requirement for a relational marketplace workload.
