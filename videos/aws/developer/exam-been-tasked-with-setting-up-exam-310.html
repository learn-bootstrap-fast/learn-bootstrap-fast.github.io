Datastore Index Admin gives index management capabilities that Firestore uses for composite indexes. It allows creating, updating, and deleting index definitions without granting access to document reads or writes. Firebase Rules Admin allows managing and releasing Firebase security rules for Firestore and it does not include data access permissions. Used together, these roles meet the functional requirements with least privilege.

roles/firestore.viewer is incorrect because it grants read access to Firestore documents and it does not allow creating or updating composite indexes or publishing security rules. The requirement explicitly prohibits any data reads.

roles/firestore.admin is incorrect because it grants broad administrative access that includes reading and writing document data. This violates the constraint to avoid any data access.

roles/firestore.editor is incorrect because it is not a valid predefined Firestore role and an editor-style permission set would allow modifying data which conflicts with the no data access requirement.
