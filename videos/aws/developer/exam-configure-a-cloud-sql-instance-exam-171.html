The correct option is Create a Cloud KMS key ring in us-central1 and a key then set the Cloud SQL instance to use CMEK and explicitly select the created key.

Cloud SQL for PostgreSQL requires the CMEK key to be in the same region as the instance, so creating the key ring and key in us-central1 is mandatory.
