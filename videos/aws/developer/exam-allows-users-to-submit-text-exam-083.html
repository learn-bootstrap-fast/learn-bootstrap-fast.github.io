The correct choice is Keep the raw reviews in Cloud Storage use Cloud Natural Language API for sentiment and trigger a Cloud Function on a schedule via Cloud Scheduler to generate a quarterly report.

This approach uses fully managed services that minimize operational overhead and cost. Cloud Storage is inexpensive and durable for keeping raw text. The Natural Language API provides managed sentiment analysis and text classification without the need to build or train a model. A Cloud Function can orchestrate processing and aggregation, and Cloud Scheduler provides the quarterly trigger. The function can write the summarized results back to Cloud Storage which keeps the design simple and low cost.

Set up Cloud SQL to store the feedback data and run custom sentiment scripts on Compute Engine instances and schedule the jobs every 90 days with Cloud Scheduler is heavier to operate and more expensive for this use case.
